Your JSON logs, finally readable.

Beacon tails a log stream, filters it with plain expressions, and prints each record as something a human can scan. No config file, no daemon, one binary.

What it does

Reads any JSON stream

Point it at a file, a pipe, or stdout from a container. Mixed and malformed lines pass through untouched instead of crashing the run.

Filters without a query language

Write level = error and took > 5s. Fields are matched by name, so you don't need to know the shape of the record first.

Stays out of your pipeline

Output is line-oriented and colour-free when it isn't a terminal, so grep, jq, and your CI logs all keep working.

Quick start

  1. Install it. Binaries are also on the releases page if you'd rather not use Homebrew.

    brew install beacon

  2. Pipe a log file through it to see the default formatting.

    cat app.log | beacon

  3. Narrow it down to what you're chasing.

    tail -f app.log | beacon --where 'service = checkout and level = error'

That's the whole surface area. Everything else — custom field ordering, JSON output, exit codes for CI — is covered in the docs. Bug reports and pull requests are welcome on GitHub.
